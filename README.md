# いきものクイズ

日本の野鳥・虫・魚・キノコ・木・花 325 種を、写真と鳴き声のクイズと図鑑で覚えるアプリです。

- 遊ぶ: https://yone110588.github.io/ikimono-quiz/
- iPhone は Safari の共有ボタン →「ホーム画面に追加」で、アプリのようにアイコンから開けます

このリポジトリは公開用です（アプリに必要なファイルだけを入れています）。

## 写真・音声のクレジット

写真と音声は [iNaturalist](https://www.inaturalist.org/) の観察記録から、撮影者・録音者が定めたクリエイティブ・コモンズ・ライセンス（CC0 / CC BY / CC BY-SA / CC BY-NC / CC BY-NC-SA）に従って使っています。撮影者・録音者・ライセンス・出典は、アプリ内の各写真の下とクレジット画面（`#credits`）に載せています。写真は縮小・切り抜き、音声は15秒に切り出し・音量を調整しています。
